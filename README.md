
# 🔭 OPTICS LAB – Interactive Physics Learning Website

OPTICS LAB is an interactive educational website designed to make the topic **Image Formation by Mirrors and Lenses** easier and more interesting for students.

The website combines simple explanations, visual learning, an interactive simulation, real-life applications and a short quiz.

## 🌟 Features

- Simple explanations of reflection, refraction, principal focus and focal length.
- Interactive simulation for:
  - Concave mirror
  - Convex mirror
  - Convex lens
  - Concave lens
- Adjustable object distance, focal length and object height.
- Schematic ray diagram.
- Image position, size, nature and orientation.
- Real-life applications of mirrors and lenses.
- Prediction challenge.
- Five-question interactive quiz.
- Light and dark theme.
- Responsive design for computers, tablets and mobile phones.

## 🚀 How to Run the Website

1. Download all four project files.
2. Create a folder named `optics-lab`.
3. Put all four files inside that folder.
4. Open `index.html` in your web browser.

No installation is required.

## 🌐 How to Publish on GitHub Pages

### Step 1: Create a GitHub repository

1. Open https://github.com
2. Sign in to your GitHub account.
3. Click the **New repository** button.
4. Enter the repository name: `optics-lab`.
5. Select **Public**.
6. Click **Create repository**.

### Step 2: Upload the files

Upload these four files into the main repository folder:

- `index.html`
- `style.css`
- `script.js`
- `README.md`

Make sure that `index.html` is directly inside the main repository folder.

### Step 3: Enable GitHub Pages

1. Open your repository.
2. Go to **Settings**.
3. Select **Pages** from the sidebar.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

### Step 4: Open your website

After GitHub finishes publishing, your website will be available at:

`https://YOUR-USERNAME.github.io/optics-lab/`

Replace `YOUR-USERNAME` with your GitHub username.

## 🎯 Learning Objectives

After using this website, students should be able to:

1. Explain basic reflection and refraction.
2. Identify different types of mirrors and lenses.
3. Understand the role of focal length.
4. Describe how object position affects image formation.
5. Identify real, virtual, erect, inverted, enlarged and diminished images.
6. Connect optical devices with everyday applications.

## 🧪 Important Note

The ray diagram in this starter project is schematic and intended to support visual understanding. It is not a complete optical ray-tracing model. For formal Physics demonstrations, verify the ray paths and image positions with standard textbook diagrams.
